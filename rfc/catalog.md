# **Requests for Comment (RFC) Registry**

This is the authoritative registry for all current and historical RFCs. It
provides the next available permanent ID and supports duplicate detection,
relationship checks, and links to the full documents. RFCs are not classified
by taxonomy; proposed taxonomy is optional guidance for resulting ADRs or
Standards.

| **ID** | **Title**                          | **Description**                                                                 | **Proposed Taxonomy** | **Status**   | **Last Updated** |
|--------|------------------------------------|---------------------------------------------------------------------------------|-----------------------|--------------|------------------|
| RFC-0001 | [Virtual App Hosting](../examples/virtual-app-hosting-example.md) | Proposal for hosting virtual applications on shared infrastructure. | `6200.2400` | Draft | 2026-02-20 |
| RFC-0002 | Adopt Kubernetes | Proposal to adopt Kubernetes for container orchestration. | `5400.2400` | Accepted | 2026-01-10 |

---

### **Key Fields**
- **ID**: A permanent identifier for the RFC (e.g., RFC-0001).
- **Proposed Taxonomy**: Optional guidance for resulting ADRs or Standards; it does not classify the RFC.
- **Title**: The name of the RFC, linked to the full document.
- **Description**: A short summary of what the RFC covers.
- **Status**: Indicates whether the RFC is "Accepted," "Rejected," "Draft," or "Superseded."
- **Last Updated**: The date the RFC was last modified.

---

### **How to Use This Catalog**
1. **Find an RFC**: Use the table above to locate the RFC you need.
2. **View Details**: Follow the document link when one is present.
3. **Propose Changes**: To update or supersede an RFC, submit a new RFC or ADR.

Add every new RFC to this registry; do not create a separate index.
