# Exception Request Template

This template is used to request an exception or waiver from an existing governance standard, policy, or process. All exception requests must be reviewed and approved by the appropriate governance body.

Exceptions are governance records, not reusable taxonomy classifications. An
approved exception MUST reference the Standard or ADR it modifies or deviates
from, inherit that record's taxonomy for discovery, and include an owner,
justification, approval, scope, and expiration date.

## Approval Workflow

1. **Submission**: Submit the completed exception request to the governance body.
2. **Review**: The governance body reviews the request and may request additional information.
3. **Decision**: The governance body approves, denies, or requests modifications to the exception request.
4. **Documentation**: Approved exceptions are documented and tracked.
